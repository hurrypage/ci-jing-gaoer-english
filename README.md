# 词境 · 高二英语复习

面向上海普通高中高二学生的离线优先英语学习原型。它把每天的词汇、搭配、语法、双向翻译和应用练习安排成可复习的任务，并把周末用于陌生语境迁移与复盘。

## 学习入口

首页“开始今天的学习”会进入学习中心：

- **今日学习**：当天固定任务，优先安排到期项目；
- **专项训练**：词汇、搭配、语法、完形、证据推断、衔接、翻译和写作任务识别；
- **词汇范围**：3,099 条国家课程标准词汇记录的离线检索。

“专项”不在主导航单独出现。17 项能力路径和年度安排位于“计划”页，用于系统分析，不占用学生每天的学习入口。

## 一年倒计时控制

计划页以 365 天、44 个有效学习周为预算，设置：800 个核心学习单元、每周最多 20 个新增单元、复习优先和内容供给预警。

- 到期复习超过 12 项时，当天自动暂停新增；
- 每个核心单元必须完成间隔复习、输出与陌生语境迁移，才可标为掌握；
- 仪表盘会显示距离目标、稳定复习项目、复习债务和内容供给缺口。

当前的 30 张编辑练习不足以覆盖年度目标，因此仪表盘会明确报告内容缺口，而不会虚报年度完成率。

## 当前内容与边界

当前有 **30 张编辑练习卡**，覆盖词义、搭配、双向翻译、语法和句法应用；专项页含 8 道形式对齐练习。它们都不是上海高考正式真题。

词汇范围来自本地《国家课标词汇底表（2025修订）结构化索引》；站内仅保存了可发布的最小检索字段。该索引不代表上海词频、上海专属词义、搭配、例句或正式真题。

能力地图来自本地研究资料中的 17 项核心能力记录，只用于训练路径与题型说明，不包含题目原文和答案。

上海专属真题、题频、听说材料只有在来源、场次、题文及答案完成核验后才能进入训练。目前正式真题为 **0 题**；候选卷、回忆版、付费预览和网络转载一律隔离。

## 学习规则

每日队列优先安排到期卡，再加入词汇／搭配、双向翻译和应用卡，最多八项。学生在显示答案后按真实回忆情况选择：

- **忘记了**：十分钟后短时重学；
- **有点难／记住了／很轻松**：按间隔安排后续复习；
- **太简单，不再出现**：该词及关联搭配、翻译退出主动队列；可在“数据”页恢复。

中译英和英译中会保存提交前的答案，并随学习记录导出。周六完成三道迁移题才显示反馈；周日只汇总近七天的练习信号与待复习项。

## AI 批注

DeepSeek 可用于翻译、概要和写作的批注：检查信息遗漏、关键词、语言问题并给出一条优先修改建议。需要将网站改为服务端调用，并把 `DEEPSEEK_API_KEY` 作为部署平台的保密环境变量保存；不能把密钥写进网页、浏览器存储或导出的学习记录。

## 内容生产前置条件

要达到完整的上海高考备考系统，需要逐条审核并录入词义、词形、搭配、真实例句、易错点与训练材料；同时完成上海卷题文、答案、听说音频和评分规则的正式核验。未经核验的候选资料不能直接投入训练。
