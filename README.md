# 词境 · 高二英语复习

一个离线优先的高二英语闪卡原型。学生可以完成当天的语境词义、搭配与语法应用卡，按回忆难度安排下一次复习，并把学习记录导出为 JSON 备份。

## 当前功能

- 每日到期复习与少量新卡；
- 主动回忆后自评“忘记了 / 有点难 / 记住了 / 很轻松”；
- 本地保存复习记录、下次复习日期与学习天数；
- 导入和导出学习记录；
- 清楚标识内容来源和真题核验边界。

## 内容边界

首版有 12 张人工审核练习卡。词汇范围参考本地的《国家课标词汇底表（2025修订）结构化索引》，具体引用见 `content-source-manifest.json`。这些卡片不宣称为上海高考真题，也不构成上海专属正式词表。

上海专属真题、题频、听说材料须在本地研究库完成来源、题文及答案核验后再加入。

## 本地打开

直接打开 `dist/index.html` 即可使用；若浏览器限制本地文件下载或导入，使用任意静态文件服务器打开 `dist/` 目录。

## 后续开发

在试点验证每日负担和迁移测试前，先不要扩大卡片数量。下一阶段应接入经过版本与许可证审查的 FSRS 实现，并增加已审核的陌生语境测试材料。
